## 9. `test_env.py` — 실행 검증

- **검증 방법**: 실제 실행.
- **발견한 버그**: `yfinance` import가 `try/except`로 감싸져 있지만, 바로 아래 `yf.download(...)` 호출이 **별개의** `try/except`에 있어서, import가 실패하면 `yf`가 정의되지 않은 채 호출되어 `NameError`가 발생 → "download error: name 'yf' is not defined"라는 **원인을 가리는** 메시지가 출력됨.
- **재현**: `builtins.__import__`를 몽키패치해 `yfinance` import를 강제로 실패시켜 버그 재현.
- **수정**: import 성공 여부를 `yf is None`으로 판별해 다운로드 시도를 건너뛰고 명확한 메시지 출력.
- **수정 후 동일한 방법으로 재현 테스트** → "download skipped: yfinance import failed above"로 명확하게 출력됨을 확인.

## 10. `verify_results.py` — 실행 검증

- **검증 방법**: 정상 케이스 실행 후, 이미지 파일 하나(`images/03_volatility_volume.png`)를 임시로 옮겨서 **실패 케이스**를 직접 만들어 재실행.
- **발견한 버그**: 실패 메시지(`[FAIL] Missing image: ...`)는 정확히 출력되지만 **exit code가 항상 0** — `verify()`가 성공/실패를 호출부에 전혀 전달하지 않는 구조. CI나 `&&` 체이닝에서 쓰면 무엇이 빠져도 항상 성공으로 보임.
- **수정**: `verify()`가 bool을 반환하도록 하고 `sys.exit(0 if verify() else 1)` 적용.
- **수정 후 3단계 재검증**: 정상 상태(exit 0) → 이미지 제거(exit 1, 동일 FAIL 메시지) → 이미지 복구(exit 0).
